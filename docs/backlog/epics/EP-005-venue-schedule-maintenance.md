# EP-005 場地與開放日期維護

## 目標
支撐性 Epic。申請檢查需要「哪些場地可借」與「哪些日期不開放」的資料：R-02 寒暑假開放時間由課外組公告、
R-03 國定假日、R-04 期中期末考當週及前一週、R-05 大型考試期間皆不開放，且會隨學期與行事曆變動，
必須由承辦人在系統中維護，而不是寫死在程式中。不開放日期只決定「該日能否借用」，
不影響 R-13 的工作天計算（本階段工作天＝週一～週五，不考慮國定假日與補班）。
學期區間暫定為每年 9/1～12/31、3/1～6/30，其餘日期視為寒暑假，依 R-02 設定的開放時段開放，未設定即不開放。

## 範圍
- 包含：
  - 場地資料維護（新增、編輯、停用）；初始 8 個場地以 Alembic data migration 匯入。
  - 不開放日期／期間維護（原因類型：國定假日、考試週、大型考試、其他；僅作為不開放原因）。
  - 寒暑假（學期區間以外日期）的開放時段設定（R-02）。
- 不包含：
  - 自動匯入學校行事曆（第一版由承辦人手動輸入）。
  - 各樓館教室資料。
  - 場地收費標準。
