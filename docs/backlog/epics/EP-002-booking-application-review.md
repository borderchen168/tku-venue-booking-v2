# EP-002 場地借用申請與審核

## 目標
讓學生（社團負責人）能上網申請活動場地，並由課外組承辦人（以下簡稱「承辦人」）線上審核，
取代紙本流程；系統自動檢查開放時間、不開放日期、申請期限與時段重疊，確保核准的借用符合《學生活動場地管理要點》與《社團活動申請要點》。

## 範圍
- 包含：
  - 學生以社團名義申請臨時借用（R-11、R-12），系統檢查 R-01、R-03～R-05、R-13 與時段不重疊。
  - 學生查看自己的申請與審核結果。
  - 承辦人核准、駁回申請（R-12、R-16）。
  - 企畫書與場地配置文件附件上傳（R-10）。
  - 承辦人登錄學期固定借用為社團的「固定保留時段」（R-11）；社團每次使用前仍須送出申請並經承辦人審核（R-12）。
  - 同舟廣場加借貴賓室（R-17）。
- 不包含（第一版不在範圍）：
  - 會簽單位流程（僅課外組承辦人單一關卡審核）。
  - 校外活動、體育盃賽的 10 天申請期限（R-14）。
  - 經費預算表與經費審核（R-15 中的經費部分）。
  - 海報街校外攤商比例檢查（R-18）；海報街仍可申請，但不檢查攤商比例。
  - 退回補件：使用者決定（2026-11-06）不做退回補件，資料不完整一律駁回，由社團重新申請（原 US-008 已取消）。
  - Email / 簡訊通知（第一版僅於系統內顯示狀態與原因）。
  - 場地收費。

## 成功指標
- 不符合 R-01、R-03～R-05、R-13 或時段重疊的申請 100% 被系統拒絕（以自動化測試驗證，含併發情境）。
- 承辦人可在單一頁面完成審核，不需紙本往返。
