# EP-001 場地與借用狀況查詢

## 目標
讓任何人（不需登入）都能查看可借用的學生活動場地、各場地的借用狀況與借用紀錄，
讓社團在申請前就能找到空檔，減少衝突與往返詢問課外活動輔導組（以下簡稱「課外組」）的成本，並提升場地使用的透明度。

## 範圍
- 包含：
  - 公開的場地清單與場地資訊（名稱、類別、容納人數、說明）。
  - 公開的借用狀況（依場地、日期查看時段佔用情形，含不開放日期）。
  - 公開的借用紀錄查詢（已核准的借用，可依場地、日期區間、社團篩選）。
- 不包含：
  - 各樓館教室借用（依教務處作業辦理，不在本系統範圍）。
  - 對外（校外單位）場地借用與收費資訊。
  - 申請人個資的公開顯示（姓名、學號、聯絡方式、附件一律不公開）。

## 成功指標
- 未登入使用者可在 3 次點擊內看到指定場地某一天的佔用時段。
- 公開頁面不出現任何申請人個資（以測試驗證）。
