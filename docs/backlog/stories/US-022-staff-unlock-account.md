# US-022 承辦人以 Web 介面解除帳號鎖定

## User Story(使用者故事)
身為課外組承辦人，我想要在系統網頁上查看被鎖定的帳號並立即解除鎖定，以便學生因輸錯密碼或被他人惡意鎖住帳號時，不必等 15 分鐘或請系統管理者到主機執行管理指令，就能恢復使用。

## 背景
- Sprint 1 只提供管理指令 `python -m app.cli unlock-user --username X`（cli.md 3.4、ADR-005），需要主機存取權限，承辦人無法自行處理。
- 帳號鎖定可能被濫用來鎖住他人帳號（ADR-005 已知風險），Web 解鎖是緩解措施之一（overview.md 第 11 節 #8）。

## 驗收條件（Acceptance Criteria）
### AC1 查看鎖定中的帳號
- Given 承辦人已登入；學生帳號 `412345678` 目前處於鎖定中（US-013 AC3），帳號 `412000001` 有 2 次失敗紀錄但未鎖定
- When 承辦人開啟「帳號鎖定管理」頁
- Then 清單列出鎖定中的帳號：帳號、姓名、鎖定到期時間（Asia/Taipei 顯示）、失敗次數，以及「解除鎖定」按鈕；`412000001` 不出現在鎖定清單
- 且 清單只列出系統中**存在**的帳號；為不存在的帳號累積的鎖定紀錄不顯示（避免顯示攻擊者輸入的任意字串）

### AC2 解除鎖定
- Given 學生帳號 `412345678` 鎖定中
- When 承辦人按下「解除鎖定」並確認（POST 並帶 CSRF Token）
- Then 該帳號的鎖定與失敗次數立即歸零，以 303 導回清單並顯示「已解除鎖定：412345678」；學生隨即以正確密碼可登入
- 且 記錄解除鎖定的安全日誌（操作者 id、帳號、解除前是否處於鎖定），不記錄密碼或 Token

### AC3 帳號已不在鎖定中
- Given 承辦人開啟清單後，該帳號鎖定已自然到期或已被其他承辦人解除
- When 承辦人按下「解除鎖定」
- Then 不視為錯誤，導回清單並顯示「此帳號目前沒有鎖定或失敗紀錄」，資料不變

### AC4 學生不能使用
- Given 使用者角色為學生
- When 開啟帳號鎖定管理頁，或直接對解除鎖定端點送出 POST（帶有效 CSRF Token）
- Then 系統回應 403，不解除任何鎖定，並記錄權限拒絕的安全日誌

### AC5 未登入不能使用
- Given 訪客未登入
- When 開啟帳號鎖定管理頁，或直接對解除鎖定端點送出 POST
- Then 開啟頁面時導向登入頁；POST 的處理方式與 US-004 AC2 相同（無有效 CSRF Token → 403；帶有效登入前 Token → 303 導向 `/login`），皆不解除鎖定

### AC6 CSRF 防護
- Given 承辦人已登入
- When 解除鎖定請求缺少或帶錯誤的 CSRF Token
- Then 系統回應 403，不解除鎖定

### AC7 輸入驗證
- Given 承辦人已登入
- When 解除鎖定請求的帳號參數為空、超過 50 字、含白名單以外字元，或帳號不存在
- Then 系統拒絕（422 或 404），不變更任何資料，不顯示 stack trace

### AC8 GET 不得解除鎖定
- Given 帳號鎖定中
- When 以 GET 請求解除鎖定網址（例如被嵌入圖片或連結）
- Then 不解除鎖定（解除只接受 POST）

## 商業規則與限制
- 解除鎖定只歸零鎖定與失敗次數，**不**重設密碼；若懷疑帳號遭攻擊，承辦人可另外重設密碼（US-014 AC6）。
- 承辦人可解除任何帳號（含其他承辦人）的鎖定；承辦人自己的帳號被鎖時無法登入，仍需以 CLI `unlock-user` 或等鎖定到期。
- CLI `unlock-user` 保留，與 Web 介面並存。

## 假設
- 頁面放在承辦人的管理功能選單下；若 US-014 已完成，可由學生帳號頁連到此功能，但不是本 Story 的驗收範圍。
- 清單不需分頁（同時鎖定中的帳號預期很少）；若日後數量變多再另開 Story。

## 資安考量
- 權限：僅 `staff`，service 層檢查、預設拒絕（A01、CWE-862/863）。
- CSRF：解除鎖定為狀態變更，只接受 POST 並驗證 CSRF Token（CWE-352）。
- 輸出：帳號與姓名經 autoescape 輸出（CWE-79）。
- 日誌：記錄 `account.unlocked`（操作者為承辦人 id）；可搭配既有「帳號重複鎖定」告警規則追查（security-logging.md）。
- 個資：清單只對承辦人顯示，不顯示 Email 等非必要欄位。
- 必須有負面測試：學生 403、未登入、缺 CSRF 403、GET 不生效。
