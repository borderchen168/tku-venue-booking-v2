# US-003 公開查詢借用紀錄

## User Story(使用者故事)
身為任何訪客（不需登入），我想要依場地、日期區間或社團查詢已核准的借用紀錄，以便了解場地過去與未來的使用情形、確認某活動是否已取得場地。

## 驗收條件（Acceptance Criteria）
### AC1 未登入查詢借用紀錄
- Given 系統中有多筆已核准借用（含已過去與未來的日期）
- When 未登入訪客開啟借用紀錄頁，選擇場地「同舟廣場」、日期區間 2026-11-01～2026-11-30
- Then 列出符合條件的已核准借用，依日期與開始時間排序，每頁最多 20 筆並提供分頁

### AC2 依社團篩選
- Given 「吉他社」在本學期有 3 筆已核准借用
- When 訪客以社團名稱「吉他社」篩選
- Then 只顯示吉他社的 3 筆紀錄

### AC3 只顯示已核准且只顯示公開欄位
- Given 系統中同時有審核中、已駁回、已取消、已核准的申請
- When 訪客查詢借用紀錄
- Then 只顯示「已核准」的紀錄，欄位只有場地、日期、起訖時間、活動名稱、主辦社團；不顯示申請人個資、活動說明、附件、駁回或取消原因

### AC4 查詢條件驗證
- Given 日期區間起日晚於迄日，或區間超過 1 年，或社團名稱超過 50 字
- When 訪客送出查詢
- Then 系統拒絕查詢並顯示錯誤訊息（422），不執行查詢

### AC5 查無資料
- Given 查詢條件沒有符合的紀錄
- When 訪客送出查詢
- Then 顯示「查無借用紀錄」

## 商業規則與限制
- 借用紀錄僅含「已核准」狀態（含已發生與未來）；審核中的佔用情形在 US-002 呈現。

## 假設
- 採 README 第 4 節建議，不顯示申請人個資。
- 已取消、已駁回的申請不公開（避免揭露社團內部事務），承辦人可在後台查看。

## 相依項目
- US-001、US-006（需有已核准資料；測試可用 fixture 建立）。

## 資安考量
- 權限：公開唯讀。
- 輸入驗證：社團名稱以參數化查詢做部分比對（禁止字串拼接 SQL，CWE-89），長度 ≤ 50；日期為 ISO 格式；分頁參數為正整數且有上限。
