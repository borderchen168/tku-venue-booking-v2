# US-019 承辦人設定與解除社團停權

## User Story(使用者故事)
身為課外組承辦人，我想要對違規社團設定一段期間的停權，停權期間該社團不能申請場地，以便依《學生社團違規處理作業要點》執行取消場地借用權利的處分（R-31）。

## 驗收條件（Acceptance Criteria）
### AC1 設定停權
- Given 承辦人已登入，社團「吉他社」未停權
- When 設定停權起日、迄日與原因（1～500 字）後送出
- Then 建立停權紀錄；記錄安全日誌

### AC2 停權期間不能申請（R-31）
- Given 吉他社今天在停權期間內
- When 吉他社負責人以吉他社名義申請場地（US-004）
- Then 系統拒絕，顯示「本社團目前停權至 YYYY-MM-DD，暫停申請場地」，不建立申請

### AC3 停權不影響其他社團身分
- Given 學生同時是吉他社（停權中）與熱舞社（正常）的負責人
- When 以熱舞社名義申請
- Then 依一般規則處理，不受吉他社停權影響

### AC4 既有借用的處理
- Given 吉他社在停權期間內有未來的佔用中申請
- When 承辦人設定停權
- Then 系統列出這些申請（附 US-012 取消連結，原因類別「停權」），不自動取消

### AC5 解除停權
- Given 吉他社停權中
- When 承辦人提前解除並填寫原因
- Then 停權紀錄更新迄日為今天，吉他社可再申請

### AC6 學生不能設定停權
- Given 使用者角色為學生或未登入
- When 存取停權設定頁或端點
- Then 分別回應 403（記錄權限拒絕日誌）或導向登入頁

### AC7 驗證與 CSRF
- Given 起日晚於迄日、原因為空，或請求缺少 CSRF Token
- When 送出
- Then 分別回應欄位錯誤或 403，資料不變

## 商業規則與限制
- R-31：課外組可視情節取消社團的場地借用權利。

## 假設
- 停權以社團為單位，不針對個人。
- 違規紀錄、報告書繳交（R-30）不在範圍；停權原因以文字記錄。
- 停權狀態不公開顯示於公開頁面。

## 相依項目

## 資安考量
- 權限：僅 `staff`。
- 停權檢查放在申請 service 層（與重疊檢查同一 transaction），避免以 UI 隱藏代替權限檢查。
- CSRF Token 必驗。
