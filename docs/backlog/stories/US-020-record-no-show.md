# US-020 承辦人登記未告知放棄使用並自動停權

## User Story(使用者故事)
身為課外組承辦人，我想要登記社團核准後未使用也未告知的情形，並在同一學期累計 2 次時自動停權到學期結束，以便落實 R-22，減少場地被佔而不用。

## 驗收條件（Acceptance Criteria）
### AC1 登記未告知放棄
- Given 申請 70 為「已核准」，活動時間已結束，社團未取消也未使用
- When 承辦人在該申請按「登記未告知放棄」並填寫說明（1～500 字）
- Then 申請標記為「未告知放棄」，計入該社團當學期次數；申請人在 US-005 看到標記；記錄安全日誌

### AC2 累計 2 次自動停權（R-22）
- Given 吉他社本學期已有 1 次「未告知放棄」
- When 承辦人登記第 2 次
- Then 系統自動建立停權紀錄（US-019），起日為今天、迄日為當學期最後一天，原因為「R-22：未告知放棄達 2 次」，並提示承辦人

### AC3 只能對已結束的已核准申請登記
- Given 申請不是「已核准」，或活動尚未結束，或已取消（含逾期取消）
- When 承辦人登記未告知放棄
- Then 系統回應 409，不登記

### AC4 撤銷誤登
- Given 承辦人誤登某筆未告知放棄
- When 承辦人撤銷並填寫原因
- Then 該筆不再計入次數；若因此不足 2 次，系統提示承辦人是否解除自動產生的停權（不自動解除）

### AC5 學生不能登記
- Given 使用者角色為學生或未登入
- When 對登記端點送出請求
- Then 分別回應 403（記錄權限拒絕日誌）或導向登入頁

### AC6 CSRF 防護
- Given 請求缺少 CSRF Token
- When 登記或撤銷
- Then 系統回應 403，資料不變

## 商業規則與限制
- R-22：核准後無正當理由放棄使用且未告知達 2 次，當學期不得再申借場地。
- 已依 US-011 取消（含逾期取消）不屬於「未告知」，不計入。

## 假設
- 採 README 第 4 節：「未告知放棄」由承辦人登記，系統不自動判斷。
- 學期區間（使用者決定，暫定）：上學期 9/1～12/31、下學期 3/1～6/30。R-22 次數以「活動日期所屬學期」累計；自動停權的迄日為該學期最後一天（12/31 或 6/30）。

## 待釐清
- 寒暑假（學期區間以外）的已核准借用若未告知放棄，要計入哪個學期（前一學期、下一學期，或不計入）？
- 若登記日已在該學期結束後（例如 6/28 的活動於 7/2 才登記），達 2 次時停權期間應如何計算（停權至下一學期結束，或不停權）？
