# US-010 借用同舟廣場時加借貴賓室

## User Story(使用者故事)
身為社團負責人（學生），我想要在申請同舟廣場時一併申請貴賓室並註明用途，以便活動需要休息室或貴賓接待空間時能一次完成申請（R-17）。

## 驗收條件（Acceptance Criteria）
### AC1 同舟廣場可勾選加借貴賓室
- Given 學生申請場地為「同舟廣場」
- When 勾選「加借貴賓室」並填寫用途（1～200 字）後送出
- Then 申請成立，明細與承辦人審核頁顯示「加借貴賓室：是」與用途

### AC2 勾選但未填用途被拒絕（R-17）
- Given 學生勾選「加借貴賓室」
- When 用途為空白就送出
- Then 系統拒絕並提示「請註明貴賓室用途」

### AC3 其他場地不能加借
- Given 申請場地不是同舟廣場
- When 學生竄改請求帶入加借貴賓室
- Then 系統拒絕（422），不建立申請

### AC4 貴賓室時段不可重疊
- Given 同舟廣場貴賓室 2027-03-10 14:00–16:00 已被另一筆佔用中的申請加借
- When 另一筆同舟廣場申請在 2027-03-10 15:00–17:00 也勾選加借貴賓室
- Then 系統拒絕，提示「貴賓室該時段已被借用」（檢查方式同 US-004 AC7，需併發測試）

### AC5 核准前不得使用（R-16、R-17）
- Given 申請含加借貴賓室
- When 承辦人核准或駁回（US-006）
- Then 貴賓室與同舟廣場一同核准或駁回；公開借用狀況只顯示同舟廣場借用，不顯示用途

## 商業規則與限制
- R-17：須註明用途，經核准後才能使用。
- 貴賓室時段與同舟廣場申請時段相同。

## 假設
- 貴賓室不單獨申請，只能隨同舟廣場加借。
- 第一版不支援「核准同舟廣場但駁回貴賓室」的部分核准。

## 相依項目

## 資安考量
- 權限：同 US-004。
- 輸入驗證：用途 1～200 字；僅在場地為同舟廣場時接受此欄位。
