# US-017 承辦人維護不開放日期與期間

## User Story(使用者故事)
身為課外組承辦人，我想要依學校行事曆設定國定假日、考試週、大型考試等不開放日期，以便系統自動拒絕這些日期的申請，並在公開借用狀況中標示不開放原因。

## 驗收條件（Acceptance Criteria）
### AC1 新增不開放期間
- Given 承辦人已登入
- When 輸入起日、迄日（可同一天）、原因類型（國定假日／考試週／大型考試／其他）、說明（1～100 字，例如「期末考週及前一週」）後送出
- Then 建立不開放期間，適用所有場地；公開借用狀況（US-002）立即標示為不開放並顯示原因類型，新申請（US-004）立即被拒絕

### AC2 不開放日期只影響「能否借用」
- Given 承辦人新增任一類型（含「國定假日」）的不開放日期
- When 系統計算 R-13 的最晚申請日（US-004）
- Then 計算結果不受影響；不開放日期只用於判斷該日能否借用，工作天一律為週一～週五

### AC3 列出受影響的既有借用
- Given 新增的不開放期間內已有審核中或已核准的申請
- When 承辦人送出新增
- Then 系統建立期間，並列出受影響的申請清單（附 US-012 取消連結）；不自動取消

### AC4 編輯與刪除
- Given 某不開放期間存在
- When 承辦人修改日期、原因類型或說明，或刪除
- Then 變更立即生效（借用狀況與申請檢查同步更新）

### AC5 欄位驗證
- Given 承辦人輸入起日晚於迄日、期間超過 366 天、原因類型不在白名單、或說明為空或超過 100 字
- When 送出
- Then 系統拒絕並逐欄顯示錯誤

### AC6 學生不能維護
- Given 使用者角色為學生或未登入
- When 存取不開放日期管理頁或端點
- Then 分別回應 403（記錄權限拒絕日誌）或導向登入頁

### AC7 CSRF 防護
- Given 請求缺少 CSRF Token
- When 新增、編輯或刪除
- Then 系統回應 403，資料不變

## 商業規則與限制
- R-03：國定例假日不開放（依學校行事曆）。
- R-04：期中、期末考當週及前一週不開放（由承辦人輸入「考試當週＋前一週」整段期間）。
- R-05：學校大型考試期間不開放。
- 原因類型（國定假日／考試週／大型考試／其他）只作為不開放原因的分類與顯示，**不影響 R-13 工作天計算**。

## 假設
- 第一版不開放日期**適用全部場地**，整天不開放；不支援「單一場地」或「部分時段」不開放（可列為後續改善）。
- 國定假日由承辦人依行事曆手動輸入，不自動匯入。
- 本階段 R-13 工作天＝週一～週五，不考慮國定假日與補班（使用者決定，2026-11-06），因此本 Story 不處理補班日。

## 資安考量
- 權限：僅 `staff`。
- 輸入驗證：日期 ISO 格式、原因類型為列舉白名單、說明長度。
- 日誌：記錄不開放期間的新增、修改、刪除。
- CSRF Token 必驗。
