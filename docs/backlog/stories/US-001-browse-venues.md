# US-001 公開瀏覽場地清單與場地資訊

## User Story(使用者故事)
身為任何訪客（不需登入），我想要瀏覽可借用的學生活動場地清單與各場地資訊，以便知道有哪些場地可以辦活動、是否適合我的活動規模。

## 驗收條件（Acceptance Criteria）
### AC1 未登入可瀏覽場地清單
- Given 系統中有啟用中的場地（初始資料為 README 第 2 節的社團活動場地與海報街）
- When 未登入的訪客開啟場地清單頁
- Then 頁面依類別（社團活動場地、擺攤場地）列出所有**啟用中**的場地名稱，回應狀態為 200，不需登入

### AC2 查看場地資訊
- Given 場地「學生活動中心」為啟用中
- When 訪客點選該場地
- Then 顯示場地名稱、類別、容納人數（未設定時顯示「未提供」）、說明、可借用時段（學期間 08:00–22:00，R-01），並提供前往該場地借用狀況（US-002）的連結

### AC3 停用場地不顯示
- Given 某場地已被承辦人停用
- When 訪客開啟場地清單頁，或直接以網址存取該場地資訊頁
- Then 清單不顯示該場地；直接存取時回應 404

### AC4 不存在的場地
- Given 場地 id 不存在或格式錯誤（非正整數）
- When 訪客存取該場地資訊頁
- Then 回應 404（或 422 由統一錯誤頁呈現），不洩漏內部錯誤細節

## 商業規則與限制
- R-01：可借用時段 08:00–22:00。
- 各樓館教室不在本系統範圍，不列入清單。

## 假設
- 初始場地資料（學生活動中心、驚聲廣場、同舟廣場、覺軒花園教室、五虎崗舞蹈教室、體育館 1 樓、B1 社辦廣場、海報街）以 Alembic data migration 匯入；同舟廣場貴賓室不列為獨立場地，於 US-010 以加借選項處理。
- 容納人數初始值可參考收費一覽表，無資料時留空。

## 相依項目
- 無（場地維護介面見 US-016，但本 Story 只需 migration 匯入的初始資料）。

## 資安考量
- 權限：公開唯讀頁面，不需登入；只顯示啟用中場地。
- 輸入驗證：路徑參數 `venue_id` 以 Pydantic／FastAPI 驗證為正整數。
- 輸出：Jinja2 autoescape 開啟，場地說明不得以 `|safe` 輸出。
