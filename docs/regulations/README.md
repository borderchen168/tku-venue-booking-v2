## 3. 對系統的業務規則摘要

以下規則由產品負責人與系統分析師轉為驗收條件與設計，條號標示出處。

### 3.1 開放時間（管理要點第四點）

- R-01 學期間每日 08:00 起開放，22:00 前須撤場完畢 → 可預約時段為 08:00–22:00。
- R-02 寒暑假開放時間由課外組另行公告 → 系統需可由承辦人設定。
- R-03 國定例假日不開放（依學校行事曆）。
- R-04 期中、期末考當週及前一週不開放。
- R-05 學校大型考試期間不開放。
- → R-02 至 R-05 需要「不開放日期 / 期間」的維護功能。

### 3.2 申請（管理要點第五、六點；申請要點第三至八點）

- R-10 使用場地須申請並附**活動企畫書**、**場地配置文件**，經核准後才能使用。
- R-11 學期初由課外組召開協調會，排定每學期**固定借用**；協調後的空餘時段，社團可再上系統預約（**臨時借用**）。
- R-12 固定與臨時借用預約後都須提出活動申請，由**課外組承辦人審核**後才能使用。
- R-13 一般校內活動須於活動前 **5 天（不含假日）** 提出申請，逾期不受理。
- R-14 校外活動、體育盃賽須於活動前 **10 天（不含假日）** 提出（多半不涉及校內場地，列為參考）。
- R-15 一般活動應繳：社團活動申請表、活動企畫書、經費預算表及其他相關表格。
- R-16 活動未經核准前不得舉辦。
- R-17 借用同舟廣場可一併申請貴賓室，須註明用途，經核准後才能使用。
- R-18 海報街擺攤有校外攤商比例上限（校級活動不限；全校性市集同時段限一個活動且 ≤ 50%；一般社團活動 ≤ 15%）。

### 3.3 取消（管理要點第六點第三款）

- R-20 核准後不得任意搬遷、轉借。
- R-21 因正當理由取消，**最遲於活動前 3 天**通知課外組。
- R-22 核准後無正當理由放棄使用且未告知達 **2 次**，**當學期不得再申借場地**。

### 3.4 違規與停權（違規處理作業要點）

- R-30 違規每次列記一筆紀錄，社團須於 3 天內繳交報告書。
- R-31 課外組可視情節取消社團的場地借用權利 → 系統需支援「停權」狀態，停權期間不能申請。

## 4. 與使用案例的對照及待釐清事項

| 使用案例 | 相關規則 | 待釐清 |
|---|---|---|
| 1. 查詢場地借用狀況（任何人可看） | R-01～R-05 | 公開的「借用紀錄」要顯示到什麼程度？建議只顯示場地、時段、活動名稱與主辦社團，不顯示申請人個資 |
| 2A. 學生上網申請 | R-10～R-18 | 實務上以**社團**為申請單位，學生是社團負責人；系統是否需要建立「社團」？企畫書等附件是否要上傳（涉及檔案上傳的資安要求）？ |
| 2B. 課外組承辦審核 | R-12、R-16 | 是否需要退回補件？會簽單位是否納入系統（建議第一版不納入）？ |
| 3A. 學生取消自己的申請 | R-20～R-22 | 活動前 3 天內是否仍允許取消（建議允許但標記為逾期取消）？「未告知放棄」由承辦人登記 |
| 3B. 承辦人取消已申請的場地 | R-04、R-05、R-31 | 取消時應填寫原因並通知申請人 |
